# Flutter App - وضوح

تطبيق Flutter للواجهة الأمامية لتطبيق وضوح.

## المتطلبات

- Flutter SDK
- Dart SDK
- Android Studio / Xcode (للتطوير)

## التشغيل

```bash
flutter pub get
flutter run
```

## البنية

- `lib/main.dart`: نقطة الدخول الرئيسية
- `lib/src/ui/screens/`: الشاشات الرئيسية
- `lib/src/ui/widgets/`: المكونات القابلة لإعادة الاستخدام
- `lib/src/services/`: خدمات API وقاعدة البيانات المحلية
- `lib/src/models/`: نماذج البيانات
- `lib/themes/`: إعدادات الثيم والتصميم
