# Backend - وضوح

تطبيق Flask يوفر واجهات API لتطبيق وضوح.

## المتطلبات

- Python 3.10.6
- المكتبات المذكورة في requirements.txt

## التشغيل

```bash
python app.py
```

الخادم يعمل على http://127.0.0.1:5000

## الوحدات

- `radar_simulator.py`: محاكاة بيانات الرادار والضباب
- `analyzer.py`: تحليل الوضع وتحديد المسارات الآمنة
- `rules_engine.py`: محرك القواعد لتقييم المخاطر
